Modern ARC Architecture (Production Design)
1️⃣ Memory Model Overview

Use three memory categories:

A. Stack Objects (Default)

Fastest and no ARC needed.

func main() {
    a := Point(10,20)   // stack allocation
}

Properties:

No reference counting

Auto destroyed on scope exit

Zero overhead

Very fast

Rule:

Value types → Stack

Examples:

int

float

struct

small arrays

B. Heap Objects (ARC Managed)
user := new User("John")

Stored as:

[RefCount][TypeInfo][ObjectData]

Example layout:

+----------+
| refcount |
+----------+
| type     |
+----------+
| fields   |
+----------+

Operations generated by compiler:

retain(user)
release(user)

When:

refcount == 0

→ Destructor runs
→ Memory freed

2️⃣ ARC Rules (Core Language Semantics)
Assignment
a = b

Compiler generates:

retain(b)
release(a)
a = b
Function Call
foo(x)

Compiler:

retain(x)
call foo
release(x)
Return Value
return obj

Compiler:

retain(obj)
return obj

Caller:

release(obj)
3️⃣ Borrowed References (Very Important)

Without this ARC becomes slow.

Example:

print(user.name)

Should NOT increase refcount.

Solution:

borrow user

Example design:

func print(u &User)

Meaning:

Borrowed reference
No retain
No release

Benefits:

Much faster

Cleaner code

Prevents ARC explosion

Swift and Rust both have this concept.

4️⃣ Weak References (Required)

To break cycles.

Example:

class Node {
    parent weak Node
    children List<Node>
}

Weak reference:

parent weak Node

Properties:

Does not increase refcount

Automatically becomes null when freed

Runtime structure:

StrongRef -> Object
WeakRef -> WeakTable -> Object
5️⃣ ARC Optimizations (Very Important)

Without optimization ARC becomes slow.

Optimization 1 — Retain/Release Elimination

Bad:

retain(x)
release(x)

Compiler removes both.

Optimization 2 — Temporary Elimination
foo(new User())

Should produce:

allocate User
call foo
release User

Not:

retain
release
retain
release
Optimization 3 — Stack Promotion
u := User("John")

If not escaping:

→ stack allocate instead of heap.

Huge speed improvement.

6️⃣ Destructor Model

Objects have destructors:

class File {
    func destroy() {
        close(fd)
    }
}

Called automatically when:

refcount == 0

Equivalent to:

C++ RAII

Swift deinit

7️⃣ Zero-cost Value Types

Important feature:

struct Vec3 {
    x float
    y float
    z float
}

Properties:

Stack allocated

No ARC

Copy by value

Very fast

Essential for HPC.

Perfect for your cluster workloads.

8️⃣ Thread Safety Choice

Two options:

Option A — Non-Atomic ARC (Recommended)

Fast:

refcount++

Best performance.

Downside:

Not thread-safe.

Solution:

Objects must not be shared across threads without special types.

Option B — Atomic ARC
atomic_inc(refcount)

Thread-safe.

But slower.

Best Design

Use two object types:

shared User   -> atomic ARC
local User    -> non-atomic ARC

Swift does similar internally.

9️⃣ Optional Manual Free (Advanced)

Allow:

free(user)

Compiler turns off ARC for that object.

Useful for:

HPC

Buffers

Big arrays
